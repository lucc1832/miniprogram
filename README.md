## 功能与下载速查

小小工具箱微信小程序：到期便签/使用成本、天气、纪念日、厨房、体重与经期记录、云端数据管理；部分模块仍为演示或占位。

### 下载到另一台电脑

- [下载源码 ZIP](https://github.com/lucc1832/miniprogram/archive/refs/heads/main.zip)，或在仓库页面选择 **Code → Download ZIP**。
- 使用 GitHub CLI：`gh repo clone lucc1832/miniprogram`。
- 整理时未发现本仓库 Releases 的安装包附件；上述 ZIP 是源码/资料，不是现成安装包。原说明中的其他下载入口见下文。

### 使用与迁移

使用微信开发者工具导入源码，按自己的 AppID 配置云开发、天气和 OCR 等服务。详细完成度见 UI_FUNCTION_INVENTORY.md；记账未开发，厨房等部分功能为演示。

说明依据本仓库文档与源码整理于 2026-09-23；此次整理未运行应用或活动脚本。
